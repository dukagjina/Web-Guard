ABOUT THE APP

Web Guard

A focused Windows blocker for known dangerous websites.

v—

What it blocks

Known malware, ransomware, phishing, scams, abusive sites, redirect threats and cryptojacking domains. The six categories can be controlled individually.

How it works

The Windows service checks DNS requests against the bundled indexed database. Blocked domains receive no destination address. Allowed requests use certificate-verified Cloudflare DNS over HTTPS by default, or the original system resolver if selected. Supported-browser DNS policies are restored when protection turns off.

What stays private

Requested domain names are never saved by Web Guard. Only aggregate totals remain in memory. With encrypted DNS enabled, allowed requests are sent securely to the selected DNS provider instead of being visible as plain DNS on the local network.

Limits and counters

This is not a VPN or antivirus. A browser VPN—including Opera’s built-in VPN—handles browsing and DNS inside its own tunnel, beyond a Windows DNS filter. Web Guard never turns VPNs off; it reports detected conflicts instead. The blocked total counts DNS requests, including background retries—not websites visited.

Data and local rulesThreat lists come from The Block List Project. Domain endings are validated against the bundled IANA root-zone list. Allow rules apply to subdomains and override downloaded lists.
